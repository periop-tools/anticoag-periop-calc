# 抗凝血停復藥計算機

門診用的離線小工具：選好手術日期、出血風險、麻醉方式與病人正在服用的抗凝血／抗血小板藥物，
直接算出**最後一劑吃到哪一天、哪天開始停藥、術後什麼時候可以吃回去**。

## 👉 直接開啟

**https://periop-tools.github.io/anticoag-periop-calc/**

點開就能用。**單一 HTML 檔、完全離線運作**——不連任何伺服器、不上傳任何資料，
你輸入的年齡、體重、Cr、INR 全部只留在自己的瀏覽器裡，關掉就沒了。

想在沒有網路的診間用，可以在頁面上按 `Ctrl+S` 存成檔案放桌面，之後雙擊即可，功能完全一樣。

## 依據

| 欄位 | 來源 |
|---|---|
| 手術本身的停藥／復藥時間 | 台中榮總藥學部《手術前後易出血藥物停藥／復藥時間建議》2026.05 |
| 半身麻醉／硬脊膜外／深層阻斷 | ASRA Evidence-Based Guidelines 第五版<br>Kopp SL, et al. *Reg Anesth Pain Med* 2025;0:1–29. doi:10.1136/rapm-2024-105766 |

**兩者衝突時取較長者**——前者防的是手術切口出血，後者防的是脊髓／硬脊膜外血腫（罕見但可致癱）。
工具的「最終建議」已經自動幫你取較保守的那一個，並會標明採用的是哪一邊。

## ⚠️ 使用前必讀

- 本工具依上述兩份文件編製，屬**彰化秀傳麻醉科內部共識草案，尚未經科務會議討論核定**，僅供教學與臨床輔助。
- 所有時間都是**最短等待時間**。高齡、腎功能不全、多重抗凝併用、血性穿刺時應再延長。
- 是否停藥必須同時衡量**停藥後的栓塞風險**。近半年內心導管、機械瓣膜、3 個月內瓣膜置換或修補、
  雙線抗血小板、2 週內中風、3 個月內顱內外支架者，請先會診處方醫師。
- **所有臨床決策仍以主責醫師之判斷為準。** 本工具不取代臨床判斷，作者不承擔使用本工具所生之責任。

## 計算規則

- 以「**天**」為單位的術前停藥：依原表規則，**手術當天不算**。
  例：停 5 天、手術 8/14 → 停藥日為 8/9～8/13，最後一劑是 8/8（該日整天仍可服用）。
- 以「**小時**」為單位者（DOAC、肝素等）：以手術當天 **08:00 開始麻醉／置針、12:00 結束並止血良好**估算。
- 原文是範圍值時（如 3–7 天），一律取**最保守（最長）**那一端計算日期，較短端會在註記裡標示。
- 需要腎功能或 INR 才能判斷的藥（DOAC、Fondaparinux、Warfarin），選到才會跳出對應欄位；
  未填時一律取最保守值。CrCl 可直接填檢驗值，或填年齡／體重／性別／Cr 由 Cockcroft-Gault 自動計算。
